# Task Management Application

A task management web application built with **Spring Boot** and **React**.

## Features

* Create and manage tasks
* RESTful API
* Database persistence
* Frontend-backend integration

## Technologies

* **Backend:** Java, Spring Boot, Spring Data JPA
* **Frontend:** React, JavaScript
* **Database:** H2
* **Tools:** Maven, Git, GitHub

## About

This project was developed as a practical project to explore **Spring Boot backend development**, REST APIs, JPA, and communication between a frontend application and a backend API.
